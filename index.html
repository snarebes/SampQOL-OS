SampQOL OS User Manual

This manual is for SampQOL OS 0.2.0.

This manual shows only what SampQOL OS adds or changes. For all other functions, see the stock MPC Sample User Guide.

Introduction

What is SampQOL OS?

SampQOL OS is a mod for the MPC Sample. It adds functions that stock 1.3.0 does not have, for example a mixer with inserts on pads, tracks and submixes, a Step Edit with a Track View, recording directly into the sequence, a looper, an EQ for each pad, export of stems, more drum tracks, a tuner, a sidechain and MIDI out for each track.

The functions stay close to the MPC workflow. The ideas come from different sources, most of all from the MPC One, Live and X.

  • The mod starts by itself from the microSD card. Without the card, the MPC starts as stock 1.3.0.
  • Your projects stay normal MPC projects. On a stock MPC Sample, the project opens, but the mod functions do not work there. See Compatibility and limitations.

Is it safe?

SampQOL OS does not change the stock firmware or the system files. A stock function runs a script from the SD card at start-up (the autorun folder). The script starts the stock MPC Sample software with the mod next to it. The mod is only in the memory (RAM): when you set the MPC off, it is gone.

Important: You use SampQOL OS at your own risk. SampQOL OS is a free mod. It is not a product of Akai Professional or inMusic, and they do not give support for it.

Tip: An error in the mod can stop the software while you play. Then you lose what you did not save. Save your project often, and keep a copy of your important projects.

About this manual

Knobs on SampQOL screens

K1–K3 on the SampQOL screens act as stock knobs. They follow MIDI Config > Parameter Takeover:

  • Pickup: the value does not move until the knob reaches it. A small arrow next to the knob shows which way to turn.
  • Scaled: the value moves from where it is. The value and the knob reach the end together.
  • Instant: the value goes to the knob position at once.

The FADER follows MIDI Config > Fader Takeover.

On a SampQOL page with its own K1–K3 (EQ, Tail, Scale, Kill EQ, an effect page), the ENCODER changes the last knob that you turned, in small steps. Push the ENCODER to go to the next knob (SHIFT: the previous knob), as in stock Chop Mode. With SHIFT held, the ENCODER changes the SHIFT value of that knob.

On the Play page of SAMPLE, hold SHIFT and turn the ENCODER to change the knob in the focus box: Keys (K1), Pad Link (K2) or Stereo (K3). Push the ENCODER to move the focus box.

Four knobs step with the turn and never jump: Keys (SHIFT + K1), Export (K1), the track color (K1) and the two EQ crossovers together (SHIFT + K2).

Installation and start-up

You need:

  • A microSD card with the format exFAT. The card can have any name.
  • A computer (Mac or Windows) with a card reader.
  • The zip file of SampQOL OS, for example SampQOL-OS-v0.2.0.zip. Use the file with the highest number.

Install

  1. Check the MPC. Start the MPC without the SampQOL card. Push and hold SHIFT and push PAD 8 – MIDI CONFIG. The top right of the display must show v1.3.0 (full number 1.3.0.12). If not, see Troubleshooting. When SampQOL OS runs, the display shows the SampQOL OS version there.
  2. Copy. Unzip the zip file. Put the microSD card in the computer. Drag the folder autorun from the unzipped folder onto the card (Mac: in Finder; Windows: in File Explorer). Then eject the card.
  3. Start. Set the MPC off. Put the card in the MPC. Set the MPC on.
  4. SampQOL OS starts by itself. You do not push a button.

The display shows the SAMPQOL logo, the version (v0.2.0) and beatops.io/SampQOL until the app is ready.

Every start

You cannot select stock at start-up. To start stock 1.3.0, set the MPC on without the SD card, or see Go back to stock.

To see if the mod runs: MIDI Config (SHIFT + PAD 8) shows the mod version top right, for example QOL-0.2.0 (stock: v1.3.0).

SD Card Access (SHIFT + PAD 16) works as in stock, also with a card named MPC SAMPLE. If the MPC shows SD card is busy, do not copy files: push B3 (OK), push Exit and try again. If SampQOL OS crashes during SD Card Access, see The computer lost the SD card.

Watchdog

A watchdog monitors the mod. If the mod crashes, the watchdog starts SampQOL OS again in a few seconds. You lose only what you did not save. If the mod crashes again within 2 minutes, the MPC starts as stock. Each crash is written to the folder autorun/logs on the card (last-exit.log holds the crash details). Send this folder with a bug report.

Project safety net

At each start-up (before SampQOL OS starts) and after a crash, stock can load the open project and delete samples that only SampQOL OS uses. Thus SampQOL OS keeps a copy of the open project in the background. A sample in the copy uses no extra space while the project has it. An erased sample stays in the copy until the project no longer uses it, or until the internal storage has less than 512 MB free. When SampQOL OS starts:

  • If stock did not change the project, the missing samples come back, without a message.
  • If stock changed the project, your last SampQOL OS version is the project QOL-Recovery-<date> (Projects > User). After the load, the SAMPLE screen asks RECOVERY with its name:
    • B3 (Load): loads your last SampQOL OS version. Save then offers the name of your original project. The QOL-Recovery project stays.
    • B2 (Delete): deletes the QOL-Recovery project and its samples. Your open project does not change.
    • B1 (Cancel): keeps the QOL-Recovery project. The MPC does not ask again for it.

Tip: A stock question that opens over RECOVERY closes it; the MPC asks again at the next start. You can also load or delete a QOL-Recovery project in the browser.

Two rules

Important: SampQOL OS is only confirmed to work with 1.3.0. After a firmware update, it will probably not work. Ignore the updates on the Akai web page (mpc-sample.local) and in the inMusic Software Center.

Important: Save your project before you put the card in an MPC that is on. SampQOL OS then starts at once and restarts the MPC software, and you lose what you did not save.

Go back to stock or install a new version

  • Stock for one session: start without the SD card.
  • Stock with the SD card in (for example, to use your projects on the card): on a computer, rename the folder autorun (for example to autorun-off) or move it into another folder. The MPC starts SampQOL OS only from a folder autorun directly on the card. To start SampQOL OS again, put the name and place back.
  • Stop for good: delete the folder autorun from the card.
  • New version: delete the folder autorun from the card. Then do step 2, 3 and 4 of Install with the new zip file. Your settings stay: mpcqol.conf is on the top level of the card, not in the folder autorun.

Settings

  1. Push and hold SHIFT and push PAD 8 – MIDI CONFIG.
  2. Push B2 to go to Settings. If Shortcuts > Shift+Pad 8 is Settings, the MPC skips this step.
  3. Turn the ENCODER to select a line.
  4. Push the ENCODER (the line becomes blue), turn it to change the value, and push it again. A line with > opens its list.
  5. Push B1 (Back) or B2 to go back to MIDI Config.

The mod saves the settings on the SD card (mpcqol.conf).

View Follow

View Follow sets what the Pad View and the Track View follow while the sequence plays: Follow Playhead (the view scrolls with the playhead, the cursor stays) or Follow Cursor (the view stays at the cursor). Set a Shift+Pad to View Follow. Each push of SHIFT + that pad sets the other value, with a popup.

Tip: Turn the ENCODER or push - or +: Follow Playhead stops until the next start of the sequence. The MPC keeps your choice after a restart.

Sample Mode

The SAMPLE screen header

The SAMPLE screen shows the sequence and the track before the pad, for example "S01 T02 A01" (T03+ = a new track).

  • While you hold SEQ or PAD BANK, S01 or T01 is red and the name field shows the sequence or track (that you will get).
  • While a selected sequence waits for the end of the loop, S01 is red and the name field shows "Next" and its name.
  • While you hold SAMPLE, A01 is red. SAMPLE + pad selects that pad without sound (stock).

EQ page

Each pad has a 3-band EQ, directly after the filter. At 0 dB, the EQ does not change the sound, and it uses no extra CPU.

  1. Push SAMPLE and select a pad.
  2. Push B3 until the EQ page shows (Filter > Flt Env > EQ).
  3. Turn the knobs:
    • K1 = Low, K2 = Mid, K3 = High.
    • Fully left = the band is off (kill). Center = 0 dB. Fully right = +6 dB.
  4. Crossover points:
    • SHIFT + K1 = crossover Low/Mid (40 Hz – 1 kHz).
    • SHIFT + K3 = crossover Mid/High (600 Hz – 15 kHz).
    • SHIFT + K2 = moves the two crossovers together.

The window shows a live spectrum of the pad (after the EQ) with the EQ curve. For the ENCODER, see Knobs on SampQOL screens.

  • Automation: turn K1–K3 during SEQ RECORD and PLAY.
  • Erase automation: push and hold ERASE and turn K1, K2 or K3 on the EQ page. With SHIFT, you erase the crossovers.
  • The project saves the EQ values for each pad.
  • Bypass: SHIFT + B3 on the EQ page: all pads play without the EQ, and the knobs show grey. Push again to hear the EQ. Bypass goes off when you leave the EQ page. The project does not save it.
  • Mixer: PAD FX goes to the inserts of the pad. B3 on the row EQ comes back. See Mixer.

Tip: The EQ plays only on the MPC Sample with SampQOL OS. For an EQ that plays on every MPC, put an EQ effect on the pad as an insert in the Mixer.

Sample Tail

With Tail, the end of a sample (or chop) sounds longer: the last part plays back and forth (ping-pong) and fades out, so a chop does not stop abruptly.

  1. Push SAMPLE and select a pad.
  2. Push B1 until the Tail page shows (Trim > Mix > Amp Env > Tail).
  3. Turn the knobs:
    • K1 = Start: the size of the part that plays back and forth (4 ms to 1 s), with a blue line in the waveform.
    • K2 = Length: how long the tail sounds (4 ms to 5 s). Fully left = Off (default).

To erase the Tail automation of the pad, hold ERASE and turn K1 or K2.

  • Tail does not work when Loop is on.
  • The pad light stays bright while the tail plays.
  • In Chop Mode, Tail is for the selected chop.
  • The project saves the Tail values.

Stereo: one channel of a stereo sample

With Stereo, a stereo sample plays only its left channel, only its right channel, or a blend. The channel plays in mono, on both speakers.

  1. Push SAMPLE and select a pad.
  2. Push B2 until the Play page shows.
  3. Hold SHIFT and turn K3 (Stereo):
    • St (centre, default): the sample plays in stereo, as in stock.
    • L Mono (fully left): only the left channel, on both speakers.
    • R Mono (fully right): only the right channel, on both speakers.
    • L1 to L49, R1 to R49: a blend. The other speaker plays more of the channel that you keep. The higher the number, the more mono the sound is.

K3 follows MIDI Config > Parameter Takeover, as the other SampQOL knobs (see Knobs on SampQOL screens).

  • A mono sample does not change.
  • The project saves the Stereo value of each pad.
  • A turn during SEQ RECORD + PLAY does not record automation.

Tip: Put L Mono and R Mono on two pads with the same stereo sample: each pad plays one side as its own mono sound.

Tip: For left and right together as one mono sound, keep Stereo at St and put AIR Stereo Width with Width 0 % in a pad insert slot.

Tip: On a stock MPC Sample and on an MPC One, Live or X, the pad plays both channels. To keep the result in the sample, use Resample one pad first.

16 LEVELS Scale

With Scale, the 16 pads play the sample of one pad on the notes of a scale. You can also play a chord on each pad, or an arpeggio (Arp).

  1. Push SAMPLE and select a pad.
  2. Push 16 LEVELS to set 16 Levels on.
  3. Push SHIFT + 16 LEVELS until the display shows "16 Level / Scale" (Velocity > Filter > Tune > Scale; again = Velocity).
  4. Turn the knobs on the orange bar:
    • K1 = Key (C to B).
    • K2 = Scale: Chromatic, Major, Minor, Harm Minor, Maj Pent, Min Pent, Dorian, Phrygian, Mixolydian, Blues.
    • K3 = Octave (-2 to +2).
    • The ENCODER: see Knobs on SampQOL screens.
  5. Play the pads (orange). PAD 1 plays the key, the pads above it go up the scale. Example: Key C, Major: PAD 1 to PAD 8 play C, D, E, F, G, A, B, C.

The key plays at the nearest pitch (up to 5 semitones up or 6 down). Use Octave for more. Scale uses the KEYS root note of the pad, for example "Key C (D3)". With the KEYS root Off, the sample is a C.

Chord: hold SHIFT and turn K1: Chord Off, 1-3-5, 1-3-5-7, 1-3-5-6, 1-3-5-9, 1-3-5-7-9, 1-2-5, 1-4-5, 1-5, 1-5-8. The numbers are the steps of the scale (8 = one octave up). With Chromatic, each pad plays the chord shape of Major (1-3-5 = major, 1-4-5 = sus4). On a pad in Note On mode, each recorded tone plays with its own length.

Arp: hold SHIFT and turn K2 to select a pattern: Arp Off, Up, Down, Up & Down, Converge, Diverge, Thumb Up, Pinky Up, Random. SHIFT + K3 sets the number of octaves (1 to 4).

Hold NOTE REPEAT and hold pads: the repeats play the notes of the held pads (with Chord: all chord tones) one at a time, in the pattern, from low to high. A note that two chords share plays one time. Rate, swing and recording are as stock Note Repeat.

Tip: With Chord Off, one pad plays the same note on each step. Hold two or more pads, or set a Chord.

Pad grid: B2 (Grid) shows or hides a 4×4 grid with the note (for example E3) and the chord name (for example Em7) of each pad. The pads that play the key are orange. When the grid is off, it shows for 2 seconds after you turn a knob.

  • While you hold SHIFT, the bar shows the Chord and Arp values. SHIFT + pad always does the stock function.
  • The mod saves the Scale values on the SD card, not in the project.
  • A recording is a normal 16 Levels note. The project also opens on a stock MPC.
  • A recorded chord keeps all tones, also with Time Correct (SHIFT + PAD 14): the first tone goes on the grid, each next tone 1 tick (1/960 of a beat) later. Stock keeps only one tone. This is for all 16 Levels notes, also Tune.

Tip: Set the pad to Poly (Play page, K1) to hear a chord. A pad in Mono mode plays only one tone.

Note: Scale does not work when Warp is on in mode Pitch (as stock Tune). Set Warp to Off or to Time stretch (SHIFT + PAD 15).

Two pads: a second pad stops the first, as in stock. The second pad plays until you release it.

KEYS: play a pad from a MIDI keyboard

With KEYS, a MIDI keyboard plays the selected pad chromatically. The pads stay drums; the keyboard plays your sample at pitch.

Connect the keyboard:

  1. Connect a keyboard with a MIDI output with a 1/8" (3.5 mm) TRS to 5-pin MIDI DIN cable (not included) to MIDI IN. A keyboard with only USB: use a USB MIDI host box (not included) to MIDI IN, or a computer that sends its MIDI to the MPC over USB-C.
  2. In MIDI Config (SHIFT + PAD 8), set MIDI Port to External (MIDI IN) or USB (computer), and Pad MIDI In to On.

Tip: A keyboard directly on USB-C does not work: the MPC is a USB device, not a USB host. With the wrong MIDI Port, the keyboard plays no sound.

Play: push SAMPLE, select a pad (SAMPLE + pad: no sound) and play the keyboard. C3 plays the sample at its original pitch. Chords, release per key and the sustain pedal work.

Change the root note of a pad:

  1. Push SAMPLE and push B2 until the Play page shows.
  2. Hold SHIFT and turn K1 (Keys): one step = one semitone.
    • Below C#-2 is Off: the keyboard plays the pads as in stock.
    • Below Off is Default: the pad follows Settings > MIDI Keyboard Plays. The value shows in brackets, for example "(C3)".

The project saves the root note of each pad.

Tip: The Tuner can set the root note from the note that the pad or the instrument plays.

Chopped pad: on a pad with 2 or more slices, each key from the root note up plays one slice (1, 2, ...) at the original pitch. For the pad chromatically, set Settings > MIDI Keys on Chop Pad to Pitch.

NOTE REPEAT: hold a key. The selected pad repeats at the pitch of that key.

Record: set SEQ RECORD on and play. The MPC records normal 16 Levels notes (Tune, or Slice on a chopped pad), so the project also opens on a stock MPC. Recorded chords work as in 16 LEVELS Scale.

Tip: A key does not add a note in Step Edit, as in stock. Use the pads there.

Chop Mode

128 slices: Chop Mode can have up to 128 slices on one sample. PAD BANK selects the bank (A = slices 1-16 to H = 113-128). ERASE + pad works on each bank. On a bank without chops, Chop Mode opens on bank A.

Chop by tap: with Chop Type Manual, tap pad 1 to play the sample, then tap pads 2-16 in time with it. Each tap makes a chop. After the 16th chop of a bank, the next bank shows: tap its pad 1 and continue.

Tip: A chop between two chops does not change the bank. PAD BANK while the sample plays goes to the next bank. After chop 128 the bank does not change.

Threshold and Split: Chop Type Threshold makes up to 16 slices (bank A), as in stock. Set up to 128 in Settings > Threshold Max Slices. The first slices come from the start of the sample. A lower Threshold gives more slices. Split (SHIFT + B2) splits up to 64 slices.

Regions 32, 64 and 128: K3 (Chop Type) has 8 positions: Threshold, Regions 4, 8, 16, 32, 64, 128, and Manual. When you turn K3 or the encoder, the knob shows the name of the type.

When you leave Chop Mode or go to another track there, a Threshold or Regions chop becomes Manual, as the pads that Extract makes. The slices stay. To chop again, turn K3 to Threshold or Regions.

Note: Stock MPC Sample software chops a Threshold or Regions pad again and keeps only 16 slices. A Manual pad keeps all its slices, also on a device without the mod.

Tip: After a new chop or a moved slice, the MPC saves the chops in the sample file when you leave Chop Mode. A long sample then shows a loading circle for some seconds before the waveform comes back. Without a change, the waveform shows at once.

Tip: At 64 slices or more, Split stays white but does not split. Use Merge first, or add a slice by hand.

Link Slices: when Link Slices is on, the start of the next slice moves with the end of a slice. Hold SHIFT and turn K3 (Link: On / Link: Off) for this pad. The project saves the choice of each pad. A pad with no own choice follows Settings > Link Slices Default. With Chop Type Threshold, SHIFT + K3 stays the stock Threshold.

Ask before rechop: before a new Chop Type (K3) replaces your own slices, the MPC asks "CHANGE CHOP TYPE": B1 = Cancel, B3 = Do It!. See Settings > Ask Before Rechop.

Zero crossing: with Settings > Snap to Zero Crossing = Always, Start, End, Loop, chops and slices snap to a zero crossing at every zoom, for fewer clicks.

Extract puts the chops of a pad on their own pads. It makes no new WAV: each new pad is a copy of the chopped pad, with the chop as its Start and End. The stock Extract (a new WAV for each chop) is not available.

  1. Push SAMPLE, select a chopped pad and open Chop Mode.
  2. Select a slice.
  3. Hold SHIFT and push B1 (Extract):
    • B1 = Cancel.
    • B2 = Pad: the selected slice goes to one pad.
    • B3 = Track: each chop goes to its own pad, in order, in a row.
  4. Push the pad for the chop (Pad) or for the first chop (Track). A short push of PAD BANK selects the next bank, or hold PAD BANK and push a pad to select that bank. The display shows the pads (for example "16 chops to B01-B16") and if they are empty. At the start, the first empty pad (or row of pads) is selected, or else the last pad where the chops fit (128 chops: always A01). The pad lights show the pads in the bank: yellow = a chop goes there, red = a chop replaces the sample there, white = the chopped pad. Turn K2 (Mute Grp) or the ENCODER to set the mute group of the chop pads: Off or 1-32 (one group per step of the ENCODER). At the start, it is the mute group of the chopped pad. Back keeps the value you set. In a mute group, a pad stops the other pads of that group, so a chop stops the chop before it. See Mute groups.
  5. Push a button:
    • B3 = Do It! when all the pads are empty. When a pad in the way has a sample, B3 = Replace: the chops replace the samples on those pads. With Track, this can also be the chopped pad: it becomes its own chop, with that chop as its Start and End.
    • B2 = New Track (Track only): the chops go to pads A01 and up of a new track directly after the current track. The MPC shows the new track in bank A, with pad A01 (the first chop) selected.
    • B1 = Back: back to step 3.
  6. When the chopped pad has pad insert effects, New Track asks first: B3 (To Track) puts the effects one time on the track inserts of the new track, with the same settings and on/off state (the chop pads get no effects). B2 (Copy FX) gives each chop pad a copy. B1 (Back) goes back to step 4. The chopped pad keeps its effects.
  7. The display shows "Extracted to:" and the pad or pads.
  • One UNDO removes the full Extract, also a new track.
  • With Pad, the chopped pad is never replaced. With Track and Replace, the chopped pad keeps its sample but plays only its own chop. UNDO gives back the chopped pad with all its chops.
  • SHIFT + B1 on a pad that plays only its own chop shows "Extract: 1 chop". UNDO gives back all its chops.
  • When the chops go past H16, the display shows "they do not fit" and B3 is not available. Push an earlier pad, or use New Track.
  • 128 chops fill all pads of a track, so use New Track.
  • With 16 tracks, New Track shows "16 Tracks Max".
  • Extract works only when the sequence is stopped. The notes do not change.

Sample Record Mode

All settings of the stock Input Config menu are on the SAMPLE RECORD screen. For the menu itself on SHIFT + SAMPLE, see Shortcuts.

SHIFT + B2 sets Rec Input Effects (label Input FX) on or off. On: the Knob FX goes into the recording. The input monitor follows it: dry with Input FX Off, with the Knob FX one time with Input FX On.

In stock, the monitor always goes through the Knob FX. A change of Monitor (Off, Auto, On) gives no click. The monitor follows MAIN VOLUME.

Undo and Redo (SHIFT + - / +) work on SAMPLE RECORD. While a recording runs, the MPC shows Stop the recording first.

To Seq: record directly into the sequence

With To Seq, the MPC adds the note of the new sample to the sequence.

  1. Push SAMPLE RECORD.
  2. Push B2 to set To Seq on (white box = on).
  3. Use K2 to select the recording length:
    • Seq: one loop from the start of the loop. The note is on beat 1.
    • Free: the recording starts immediately and stops when you tap the pad again. The note is at the time that you started.
  4. Tap the pad that you want to record to. After the recording, the note is in the sequence, and the pad plays at once.
  • Sequence stopped: a tap on the pad starts the sequence and the recording on beat 1 of bar 1 (with COUNT-IN on, after 1 bar). STOP during the count-in = no recording.
  • Record again on the same pad: the new take replaces the old notes of that pad; the automation stays. To add a layer, use a different pad.
  • Remove a take (also a Looper take): one Undo (To Seq A01). The old notes and the old sample of the pad come back.

Tip: To Seq is tested in 4/4 and 3/4 only.

Looper

The Looper records more than one pass over the same loop. When you stop, the MPC puts all passes on top of each other in one loop.

  1. Push SAMPLE RECORD and set To Seq on (B2).
  2. Push B3 to set Looper on (white box = on).
  3. Set K2 to Free.
  4. Tap the pad and play as many passes as you want.
  5. Tap the pad again to stop.
  • If the sum is too loud, the sound is clipped.
  • On a chopped pad, the Looper does not merge the passes, as in stock.
  • When you set To Seq off, Looper also goes off.

STOP stays on the screen

STOP stops the sequence, but the display stays on SAMPLE RECORD, for the next take. A recording that waits ("Waiting for signal") is cancelled.

Source Rear+USB

With the Source Rear+USB, the MPC records and monitors the rear inputs and the USB audio from a computer at the same time.

  1. Push SAMPLE RECORD.
  2. Turn K1 (Source) fully to the right: Rear+USB. (It is also the last Source in the stock Input Config menu and in the Tuner.)
  3. Record as usual.
  • The MPC adds the two inputs at full level. If both are loud at the same time, the recording can clip: turn one of them down.
  • Without the SD card, the MPC starts as stock with the Source Rear.

Tuner

The Tuner shows the note of one tone: a guitar or voice on the mic, the rear input or USB audio, or a sample that the MPC plays.

  1. Push SHIFT + PAD 7. The Tuner opens. (In stock, this is Double Speed: see Shortcuts.)
  2. Turn K1 (Src) or the ENCODER to select the Source: Mic, Rear, Rear+USB (the Tuner reads only the rear inputs), USB (a computer), or Resample (what the MPC plays, also with MAIN VOLUME at 0). This is the same Source as for recording.
  3. Play one note. The screen shows the note (for example A3), a needle from -50 to +50 cents, and the frequency and cents. The needle is green within 3 cents. When the sound stops, the last note stays in grey.
  4. Push B1 (Back), SHIFT + PAD 7 or a mode button to close the Tuner.

The note names use the MPC octaves, as KEYS and 16 Levels: C3 is MIDI note 60, so 440 Hz shows as A3 (A4 on a guitar tuner).

Tip: Play one note at a time: a chord or a drum hit often shows no stable note. A low guitar or bass string can show one octave too high, mostly at the start of the note.

Set the root note of a pad from its note:

  1. Select a pad on the SAMPLE screen or in Pad View. A pad that you play while the Tuner is open also becomes the selected pad.
  2. Open the Tuner. The bottom line shows the pad that gets the root note, for example "Pad T02 A05".
  3. Play the note:
    • With the Source Resample: play the pad. The Tuner reads the sample itself.
    • With a different Source (for example Rear): play the note of the sample again on the instrument. Example: you recorded an A on a guitar with Sample Record. Play the same A again.
  4. Push B3 (Apply). The note becomes the KEYS root note of the selected pad. For 3 seconds the bottom line shows the new and the old root note, for example "Pad T02 A05: root A3 (was C3)". Apply has no Undo step: to set it back, use SHIFT + K1 on the Play page of SAMPLE.

Tip: Resample always gives the note of the sample. With a different Source, play the same note as in the sample. For a chord or a riff, use Resample.

Sequences and tracks

A project can have up to 16 drum tracks. SampQOL OS loads all drum tracks of a project, also from an MPC One, Live or X. The pads play the current track, as on an MPC One or Live. Each track has its own 8 pad banks. Recording, NOTE REPEAT, a MIDI keyboard and Resample use the current track.

The mod always saves the project with track 1 as the current track. Thus a stock MPC Sample can open it safely.

Load Kit: Load Kit loads the kit into the current track. The samples of the other tracks stay. A kit sample with the same name as a sample in the project gets its own name (for example Kick1), so each track keeps its own sound. The track gets the name of the kit.

Unique track names: the project saves the notes of each track under the track name. Thus when Load Kit or Load Project gives two tracks the same name, the second track gets its own name, for example Drum 001-2.

Half Seq and Double Seq: SHIFT + pad 2 (Half Seq) and SHIFT + pad 3 (Double Seq) change all drum tracks of the sequence.

TAP TEMPO light: the TAP TEMPO light does not flash with the tempo. It stays on, a little dimmed. With SHIFT held, it shows the SHIFT colour as in stock.

Select a track

  • Hold PAD BANK and turn the ENCODER. Release PAD BANK to change the track.
  • Or hold SHIFT + PAD BANK and push pad n: track n. While you hold them, the pads show the tracks: bright green = the current track, dim green = another track, red = a muted track, off = no track. If you turn the ENCODER, the target pad is white.
  • After one turn of the ENCODER, PAD BANK alone also shows the tracks on the pads, and pad n selects track n, until you release PAD BANK. Hold only PAD BANK (no ENCODER) to see the stock bank colours on pads 1 to 8 and to select a bank.
  • While you select, the track number is red. In the Track View, the track label moves to the track that you will get.

New track: select one track past the last track (for example T03+, in the Track View a new row). The MPC makes one new track, with empty pads, empty track inserts and its own colour. One UNDO removes it.

Move a track

  1. Select the track that you want to move.
  2. Hold PAD BANK and push - (one place up) or + (one place down). The track changes places with the track next to it and stays the current track. A popup shows both tracks (or "First Track" / "Last Track": no change).

This works on all screens. Each move is one UNDO step. The pads, notes, mutes and name move with the track. A track that is named "Track n" gets the number of its new place. Names that you gave stay.

Copy a pad to another track

  1. Select the source pad. Hold SHIFT + ERASE (COPY) and push the destination pads, as in stock.
  2. While you hold COPY, turn the ENCODER to select the destination track, for example "Copy from A01 to Track 04 A02".
  3. Release. The MPC goes to the destination track.

Only the sample is copied (shared), not the notes. If a destination pad has a sample, the MPC asks first ("COPY PAD").

Select a sequence from the SAMPLE screen

Hold SEQ and push pad n: sequence n of the current pad bank. You stay on the SAMPLE screen. When the sequence plays, it changes at the end of the loop. SEQ alone opens the SEQ screen, as in stock.

Or hold SEQ and turn the ENCODER, and release SEQ. This also works in Step Edit, on all Mixer pages, and on the stock Pad FX and Flex Beat screens.

While you hold SEQ, the pads show the sequences of the pad bank: green = current, yellow = with events, off = empty, red = waits for the end of the loop.

Tip: On the Pad FX or Flex Beat screen, you can change the sequence and play the effects with the pads and KNOB FX: one screen for a live performance.

Tip: When the MPC plays and you change the sequence (also in Song mode), you can hear a short gap. This occurs more with many tracks or effects.

Select grid

While you select a track or a sequence, the display shows a 4x4 grid in pad order (pad 1 is bottom left), with the number and name in each cell.

  • Tracks: hold SHIFT + PAD BANK, or hold PAD BANK and turn the ENCODER, until you release PAD BANK.
  • Sequences: hold SEQ for 0.3 seconds, or hold SEQ and turn the ENCODER: the 16 sequences of the pad bank of the sequence that you will get. After the grid, the release of SEQ does not open the SEQ screen.
  • A thick white frame shows the track or sequence that you will get, a thin white frame the current one, a thick red frame the sequence that waits for the end of the loop. A dark cell is a muted track or an unused sequence. A new track shows as + with "New track".
  • Set Settings > Track Grid on Screen and Seq Grid on Screen to On, Off or Toggle. With Toggle, push B2 to set the grid on or off (B2 is white when the grid is on). The MPC keeps this choice.

Name a sequence

  1. On the SEQ screen, push SHIFT + B3 (Rename).
  2. Change the name as in stock, or push SHIFT + B3 (Preset) and select a name: Intro, Verse, Chorus, Bridge, Drop, Outro and more.
  3. Push B3 (Do It!). UNDO works.

A sequence gets the name "Sequence 08" when it gets its first events, as in stock. The SEQ screen shows the name in grey next to "Seq A08". Song mode shows "A01 Intro", or only "A01" for a default name.

In SEQ mode, the pad of the current sequence is green, a sequence with events is yellow, and an empty sequence is off.

Clear a song

Remove all sequences from the song at once. In stock, B2 (Remove) removes only one row.

  1. Push SHIFT + PAD 12 to open Song mode.
  2. Push SHIFT + B2 (Clear All). The song is empty. UNDO gets it back.

Tip: Stop the song first. While the song plays or when it is empty, Clear All is grey.

Quick Add: with Settings > Song Pads = Quick Add, a pad inserts its sequence at once after the selected row, without B3. Pad 1, pad 1, pad 2 = A01, A01, A02. A pad of an empty sequence inserts it too ("(unused)"), as B3 does: B2 or UNDO removes it. While the song plays, a pad does not insert.

Tip: Each row shows the tempo that plays. With BPM: GBL on the SEQ screen, this is the global tempo on all rows. Stock shows the tempo of the sequence.

Record mutes

  1. Set SEQ RECORD on and play the sequence (PLAY).
  2. Push MUTE for Mute mode.
  3. Push a pad to mute or unmute it. The MPC records each push. UNMUTE ALL (SHIFT + MUTE) is also recorded.
  • The mutes play again in each loop, only in this sequence.
  • The timing is the exact time of the push. Time Correct does not change it.
  • Recorded mutes have priority over a live push.

Tip: UNMUTE ALL also unmutes all muted tracks. Without a recording, it is one undo step: UNDO brings all the pad mutes and track mutes back. During a recording, UNDO removes the recorded pass, and the pads keep the mute state that they have then.

Tip: For a sequence that starts with a pad muted, set the pad to the correct state and record one push from the start.

Erase mutes: in Mute mode, hold ERASE and push a pad. Push B3 (Do It!). Only the mutes of that pad go.

Mute Type: Settings > Mute Type sets how a mute sounds: pad mutes (Mute mode, Pad Mixer, a pad that the Solo of another pad mutes) and track mutes (Track Mute, Ch. Mixer, Explode).

  • Audio: a pad stops at once. A track fades out in 5 ms, without a click.
  • Event: only the new notes stop; the notes that sound play to their end. A muted pad then also sends no MIDI note and does not stop the other pads of its mute group.
  • A track that you muted with the other type stays muted. One push unmutes it.

Tip: A pad with Out set to a submix or an output does not fade with an Audio track mute: its sound stops at once, with a click. Use Event, or set Out to Track.

Track Mute: mute a whole track with the pads.

  1. Hold MUTE for 0.7 seconds, or push PAD BANK + MUTE. The 16 pads are the 16 tracks.
  2. Push a pad to mute or unmute that track: green = plays, red = muted, off = no track. (In pad Mute mode, a pad that plays is yellow.)
  3. With SEQ RECORD and PLAY, the MPC records each push, as pad mutes. This works for every track, also for a track that is not the current track, and on the SAMPLE screen and the SEQ screen. Track Mute stays on when the recording starts and stops.
  4. To select another sequence, hold SEQ and push a pad (the pads show the sequences while you hold SEQ). Track Mute stays on. During play, the next sequence starts at the end of the loop.
  5. To stop Track Mute, push MUTE or SAMPLE, or open another screen.

Tip: SHIFT + MUTE unmutes all tracks, in Track Mute and on the other screens. Without a recording, it is one undo step.

Tip: Track Mute and Mute (B3) on the Ch. Mixer are one mute. The Ch. Mixer also shows a recorded track mute that plays.

Track mutes per sequence: each sequence keeps its own track mutes, as on the MPC Live: mute the track in each sequence where it must be quiet. Pad mutes are the same for all sequences. The project saves them. A project with one set of track mutes uses this set in each sequence.

  1. Copy a sequence to a new sequence (for example Seq 2 and Seq 3). The copy becomes the current sequence.
  2. Select each sequence and mute other tracks there. In Track Mute, hold SEQ and push a pad to go to a sequence without leaving Track Mute.
  3. Use the sequences as parts of a song, or in Song mode.

When you export the song to a sequence (Song > Export > Sequence), each part start gets a track-mute event for each track, as a recorded track mute. A stock MPC Sample does not play these track mutes: all tracks sound there.

The new sequence also keeps the RT Swing. A sequence holds one RT Swing per track, so each track gets the RT Swing of the first part of the song.

Tip: If later parts use a different RT Swing, set it again on the new sequence (SEQ, K3).

Tip: UNDO of a track mute changes the sequence where you made the mute, also when another sequence is selected. This is also true for the mute that Explode gives the source track.

MIDI out: a track plays an external synth

A track can send its notes on its own MIDI channel. The pads of that track then send the note that you hear: a Scale, Tune or KEYS note goes out as the real note. One track plays one part of an external synth.

Connect the synth:

  1. Connect a computer or iPad with a USB-C cable to USB-C, or a synth with a 1/8" (3.5 mm) TRS to 5-pin MIDI DIN cable (not included) to MIDI OUT.
  2. In MIDI Config (SHIFT + PAD 8), set MIDI Port to USB or External.

Set the MIDI channel of a track:

  1. Select the track.
  2. Push PAD FX, then B1 until the Track page shows.
  3. Hold SHIFT and turn K3 (MIDI). The track uses the setting at once:
    • Off: the track sends no MIDI notes.
    • Glob. (Global, default): the track sends as in stock, with the MIDI Out Channel and Pad MIDI Out of MIDI Config. A 16 LEVELS pad sends its source note.
    • Ch 1 to Ch 16: the track sends on this channel.

A track with its own channel always sends, also when Pad MIDI Out in MIDI Config is Never or When Empty. The track grid shows the channel, for example Ch 3. The project saves the setting. A new track starts with Glob. The MIDI setting has no undo.

Tip: Play more synths from one MIDI OUT: give each synth its own channel and connect them in a chain (MIDI THRU to MIDI IN), or use a MIDI thru box. Set the tracks that must not play a synth to Off. MIDI Port is for all tracks: all send on USB or all on External.

The notes on MIDI out:

  • A normal pad sends its own note. A KEYS key sends its own note. A chord and the Arp send all their tones.
  • A 16 LEVELS Scale or Tune pad sends the KEYS root note of the pad (Off = C3, note 60) plus the Tune. Example: Scale, Key C, Major, root Off: PAD 1, PAD 3 and PAD 5 send C3, E3 and G3.
  • Each pad stops only its own notes. Two held pads on the same note and channel are one note on the synth (a MIDI limit): the second pad starts it again, and it stops with the last pad.
  • The recording keeps the length of each pad, also when pads overlap.
  • STOP while the sequence plays stops all notes. When the sequence does not play, a held pad plays until you release it.

Tip: Give each synth part its own track with its own channel. On a new track or a pad with no sample, you hear only the synth. Scale, Tune and KEYS also work on a pad with no sample.

Tip: Use a source pad that the sequence does not play. A recorded note of the source pad also stops the live notes of that pad (as in stock).

Step Edit

Step Edit has two views:

  • Pad View (SHIFT + SAMPLE): one pad on each row, the steps of one page.
  • Track View (SHIFT + SEQ): one drum track on each row, 1 to 8 bars.

The two views use the same controls where possible. While you hold SHIFT, the buttons show their SHIFT function.

Tip: While the KNOB FX bar shows, B1 to B3 do the stock Step Edit functions, for example B3 is Erase. While the NOTE REPEAT bar shows, they set the Note Repeat rate. The labels at the top show these functions.

To select another sequence, hold SEQ and push a pad or turn the ENCODER (see Select a sequence). You stay in Step Edit.

A new note (a step pad, or a pad with SEQ RECORD on and the sequence stopped) is one step long, also on a One Shot pad. With SEQ RECORD and PLAY, the note is as long as you hold the pad, as in stock. FULL LEVEL (SHIFT + PAD 1) works in both views, also with Steps on.

Note Repeat works in both views (in stock, not in Step Edit): with SEQ RECORD and PLAY, hold NOTE REPEAT and a pad. The pad repeats at the Time Correct value, not the zoom. B1-B3 select the rate, as in stock. K1-K3 and the ENCODER work on the view. With Steps on, the pads play while you hold NOTE REPEAT: they do not set steps.

Pad View

The Pad View shows 8 pads (or 4, see Settings > Pad View Rows) with 16 steps. Each note is a block: the width is the length, the colour is the velocity (light yellow = soft, red = hard). A red line shows the end of the sequence.

  • ENCODER: moves the cursor one step. SHIFT + ENCODER selects the row. - / + = previous / next page.

Tip: After Resample, Project, Time Correct, the FADER menu, MIDI Config, PAD FX or SAMPLE SELECT, Step Edit comes back with the same cursor, page, Steps and selection.

Add notes with the pads (Steps)

  1. Push SHIFT + B2 to set Steps on (off when the Pad View opens). The 16 pads are the 16 steps of the page. A lit pad has a note.
  2. Tap an empty step to add a note, a set step to remove it (no sound).
  • To select another row, hold SAMPLE and push a pad (no sound; Steps stays on). While you hold SAMPLE, the pads light as on the SAMPLE screen. A short push of SAMPLE alone opens the SAMPLE screen. Hold and release SAMPLE without a pad to stay in the Pad View.
  • A tap on a step after the end of the sequence does nothing.
  • The 16 steps are 1/16, one bar (or the grid of Settings > Pad View Grid). To zoom, see Zoom below.

Play the pads (Steps off)

With Steps off (Play), the pads play, with the colours of the SAMPLE screen. The pad that you hit becomes the row. With SEQ RECORD on and the sequence stopped, a pad hit adds the note at the cursor, and the cursor goes one step on.

Edit notes with the knobs

  • K1 (Nudge) moves the notes in whole steps, inside the page (with SHIFT: fine, in ticks, up to one step to each side). The FADER moves fine. K2 (Length) sets the length (1 tick to one page; it shows the longest note). K3 (Velocity, 0 to 127; it shows the first note) sets the velocity.
  • Without a held pad, the knobs edit the selection, or the note at the cursor, in Steps and in Play. A note off the grid belongs to the cell where you see it.
  • The MPC writes the change after a half second. Each write is one UNDO step. The notes stay under the knobs until you turn the ENCODER or use another control: you can turn again after a rest.
  • Rec Quantize on (SHIFT + PAD 10): K1 puts the first note on the grid, and K2 makes the length a whole number of grid steps. With SHIFT (fine), the notes move freely.

Copy, paste and erase

  • B1 (Copy) copies the notes of the selection, or of the cell at the cursor, with their velocity, length and place in the step (no automation or pad pressure). Move the cursor and push B3 (Paste): the first step goes on the cursor step, the top pad on the cursor row. When you copied all pads (SHIFT + push the ENCODER), each note goes on its own pad. With nothing to copy, the MPC shows "Nothing to copy". If there are notes, the MPC asks Merge or Replace. Paste on the place that you copied from does nothing while the notes are still there. You can paste in another sequence.
  • SHIFT + B1 (Cut) copies the notes and removes them at once. Then Paste as after Copy. B1 (Cancel) does not put the notes back: push UNDO. The cut and the paste are each one UNDO step.
  • SHIFT + B3 works as B3 (Duplicate, or Paste after Copy).
  • ERASE alone (push and release, no pad) clears the selection, the note at the cursor, or the steps that you hold. One UNDO puts all back.
  • ERASE + pad: B2 (Page) erases the notes and automation of that pad on this page. B3 (Do It!) erases the full sequence.

Zoom (SHIFT + K3)

  • Steps on: SHIFT + K3 zooms the steps from Bar to 1/64T (at 1/32 the 16 pads are a half bar, at 1/4 four bars). Bar shows 16 bars: the pads show where the notes are, and a tap adds no note.
  • The zoom does not change your Time Correct (Rec Quantize): your value comes back when you set Steps off, go to the Track View, close Step Edit or save the project.
  • Steps off: SHIFT + K3 (Bars) zooms the view to 1, 2, 4 or 8 bars, as in the Track View. The grid does not change. The controls work on the columns that you see, and K1 and K2 in grid steps.

Rec Quantize grid: push SHIFT + PAD 10. A popup shows On or Off. Turn K3 to select the grid (Bar to 1/64T), then push B3 (Do It!) or B1 (Cancel). Without a turn, the popup closes after 2 seconds. The popup sets your own value; the zoom stays.

Track View

The Track View shows the drum tracks of the sequence. Each track has its own colour, the same as in the Ch. Mixer. The notes of the cursor track are bright, the others are dimmed. A red line shows the end of the sequence, as in the Pad View.

  • You see 4 bars. SHIFT + K3 (Bars) zooms: 1, 2, 4 or 8 bars. A column is 1/16 of the window. - / + = next or previous bars.
  • ENCODER: moves the cursor one column. SHIFT + ENCODER goes to another track. That track also becomes the current track.
  • The pads play the cursor track, with the colours of the SAMPLE screen.
  • K1 (Nudge), K2 (Length), K3 (Velocity), the FADER and Rec Quantize work as in the Pad View, inside the window you see. Nudge and Length use whole grid steps (the Time Correct value, for example 1/16). With SHIFT: fine, in ticks (up to one grid step for Nudge).
  • B1 (Copy) and B3 (Paste) work as in the Pad View, with columns and tracks for steps and pads.
  • Cut: there is no Cut button (SHIFT + B1 is Delete). Push B1 (Copy), then ERASE (the copy stays), then Paste. You can paste on the place that you cut from.
  • ERASE alone (push and release, no pad) clears the notes in the selection at once, with a short message (not for one note), and their pad pressure. Other automation stays.
  • SHIFT + B1 (Delete): see Delete a track.
  • Row labels and row count: Settings > Track View Labels and Track View Rows.

Selection

The selection works the same in both views.

  1. Put the cursor on the first cell and push the ENCODER (yellow frame).
  2. Turn the ENCODER (with SHIFT: the rows). The selection (light blue) is the rectangle from the first cell to the cursor, also past the screen (a small white arrow).
  3. The selection stays. Another button or knob (also ERASE) ends the yellow frame: then the ENCODER moves the cursor again.
  4. Push the ENCODER again for no selection.
  • B2 (Sel. Row): add the cursor row to the selection, or remove it. With no selection, this selects the whole row over the full sequence.
  • SHIFT + push the ENCODER selects all rows: all pads of the pad bank, or all tracks. With no selection, it selects them over the full sequence. Push it again for no selection.
  • With no selection, the knobs and buttons use only the cursor cell.
  • Notes move as one block: when one note would land on the same note, no note moves.
  • B3 (Duplicate) pastes a copy of the selection directly after it, in one push. The selection moves to the new part, so the next push goes on. With no selection, the new cell becomes the selection. After Copy, B1 = Cancel and B3 = Paste (once); then Copy and Duplicate come back.
  • One Copy or Duplicate takes up to 8192 notes. With more, the display shows Too many notes and nothing is copied.
  • SHIFT + PLAY plays the bars of the selection in a loop. The loop stays on other screens and after STOP: SHIFT + PLAY plays it again from its first bar. PLAY plays from bar 1 and ends the loop, as does another sequence in Step Edit.
  • To record a part again and again: STOP after each take, then SEQ RECORD and SHIFT + PLAY.
  • One UNDO puts back a clear, a move or a paste.

Automate: write a fade

Automate writes a fade of the track volume or a track filter into the selection (or the cursor cell) of the Track View.

  1. Make a selection in the Track View.
  2. Push SHIFT + B2 (Automate):
    • K1 = Start %, K2 = End % (100 % = the current value, 0 % = silent).
    • K3 = Volume, LP Filter or HP Filter.
    • SHIFT + K3 = Curve: Linear, Log (equal dB steps, natural fade-out) or S-Curve.
  3. Push B3 (Do It!), or B1 (Cancel).
  • A filter fade needs the filter as a track insert. If the track has none, the MPC adds it to a free insert slot. If all 4 slots are full, it writes nothing.
  • Master fade: select all tracks (SHIFT + push the ENCODER) and select Volume.
  • If there is volume automation in the selection, B3 shows Replace.

Remove a fade:

  1. Make a selection in the Track View and push SHIFT + B2 (Automate).
  2. Select the target with K3.
  3. Push B2 (Remove): the MPC removes the fade points of that target in the selection, on the selected tracks.
  4. To remove all fades (Volume, LP Filter and HP Filter) of the selected tracks in this sequence, hold SHIFT and push B2 (Remove All). The selection does not matter for Remove All. Release SHIFT after you open the window, then push it again: a SHIFT that you still hold from SHIFT + B2 does not count.
  • B2 shows only when there is something to remove.
  • The filter insert stays on the track. Only its fade goes.
  • In the removed part, you hear the value before it. When no fade point is left in the sequence, you hear your own value (Mixer, FADER, Pad Mix).
  • One UNDO brings back all that Remove or Remove All removed.
  • One UNDO removes the fade and gives the old volume back, also when you stopped the sequence in the middle of the fade.
  • A fade belongs to the sequence where you write it. The other sequences play your own value (Mixer, FADER, Pad Mix); 100 % in the fade is that value. A change of the volume or the filter in a sequence without the fade is your new value for all of them. UNDO of a volume change also sets that value back.
  • When you stop in the sequence with the fade, you hear the start of the fade. Before and after the selection, you hear your own value.

Tip: Write a volume fade while the sequence is stopped. If you write it while the sequence plays, UNDO keeps the volume of the STOP. Then set the volume again in the Mixer.

Tip: Set the sequence length before you write a fade to the end of the sequence. If you make the sequence longer after a fade-out, you hear your own value after the old end: write the fade again over the new length. When the project saves with the faded sequence selected, a later change of your own value in a sequence without the fade can go back after the next start: then set the value again.

Dup. Track

Dup. Track makes a copy of a track, without or with its events.

  1. In the Track View, put the cursor on the track.
  2. Push SHIFT + B3 (Dupl/Expl).
  3. Push B2 (Dup. Track). The MPC shows where the copy goes.
  4. B2 (Events) sets Events On or Off (it starts Off). On = the copy gets the events of all sequences (notes and pad automation).
  5. Push B3 (Do It). B1 (Cancel): no copy.

Track effects: when the track has track insert effects, Do It shows how many effects each choice makes. The Events choice stays.

  • B3 (To Submix): the effects go one time on the first free submix (no effects, nothing goes to it), with the same settings and on/off state. The copy gets no track effects. The Out of the track and of the copy goes to that submix. On the track the effects stay, but off. Two tracks then use the CPU of one set of effects. Without a free submix, B3 does not show.
  • B2 (Copy FX): the copy gets its own copy of the effects.
  • B1 (Cancel): no copy.

The copy is named "Track n" (n = its place). It comes directly after the track and becomes the current track. All pads, samples, pad settings, effects and routes stay. The copy shares the samples (no extra memory), is not muted and gets its own colour. One UNDO removes the copy. After To Submix, the same UNDO also puts back the effects and the Out of the track.

Tip: With To Submix, each track goes into the effects after its track volume. A reverb, delay or EQ sounds the same. A compressor or distortion sounds the same only with the track volume at 0 dB.

Tip: With 16 tracks, or on a track that is not a drum track, B2 does not show. Line 1 of the question shows why.

Explode

Explode puts pads with notes on their own new tracks.

  1. In the Track View, put the cursor on the track.
  2. Push SHIFT + B3 (Dupl/Expl).
  3. Push B3 (Explode). When Explode is not possible, the MPC shows why and B3 does not show.
  4. The MPC shows the number of pads and the new tracks. Push B3 (Do It). B1 (Cancel): no Explode.
  • Each pad with notes in the current sequence of the cursor track gets a new track, directly after the track. Pads in the same Mute Group go together to one track. The old track is muted.
  • A pad with Out set to Master goes to Track, so the track strip, volume, mute and solo work on it. A pad with Out set to a submix or another output keeps it.
  • The new tracks get the RT Swing of the old track in each sequence.
  • A track behind them that is named "Track n" gets the number of its new place. Names that you gave stay.
  • One UNDO removes the full Explode, also submix effects. Explode works only in the Track View, with the sequence stopped.

Track effects: when the track has track insert effects, step 4 shows how many effects each choice makes, and B3 is not Do It:

  • B3 (To Submix): the effects go one time on the first free submix (no effects, nothing goes to it), with the same settings and on/off state. The Out of the new tracks goes to that submix. On the old track the effects stay, but off. This uses much less CPU. Without a free submix, B3 does not show.
  • B2 (Copy FX): each new track gets a copy of the effects.
  • B1 (Cancel): no Explode.

Tip: With To Submix, each track goes into the effects after its track volume. A reverb, delay or EQ sounds the same. A compressor or distortion sounds the same only with the track volume at 0 dB.

Tip: Mute Targets (one pad stops another, from an MPC One, Live or X project) work only on one track. Put the two pads in the same Mute Group before Explode, so they go to one track.

Delete a track

In the Track View, push SHIFT + B1 (Delete). After a question, this deletes the cursor track, with its notes in all sequences. It works only with the sequence stopped. The last track always stays. A track behind it that is named "Track n" gets the number of its new place. One UNDO puts all back.

Mute groups

K2 on the Pad, Track and Submix pages of the Mixer sets the mute group (- = Off). On the Ch. Mixer and the Pad Mixer, SHIFT + K2 sets the group of the selected strip. Pads, tracks and submixes have separate groups.

  • Pad (Pad Grp): the stock pad Mute Grp (Off, 1-32): a choke. A pad stops the other pads of its group. One turn of K2 is one UNDO step.
  • Track (Trk Grp): Off or 1-8. When you mute or unmute a track, the other tracks of its group get the same mute. This works in Track Mute and with Mute on the Ch. Mixer. One UNDO puts all of them back.
  • Submix (Sub Grp): Off or 1-8. Mute of a submix on the Ch. Mixer also mutes or unmutes the other submixes of its group.

Tip: Track Mute shows the group of a track in its cell, for example G1. Solo does not follow the group. With SEQ RECORD and PLAY, the MPC records the mute of each track of the group.

Kill EQ insert

The 3-band kill EQ of the EQ page is also an insert for a track, a submix or the master, with the same knobs, crossovers and window.

  1. Push PAD FX. Push B1 for Track or Submix, or B2 for Master.
  2. Select an empty slot and push B3 (Insert).
  3. Open EQ/Filter, select Kill EQ and push the ENCODER. The Kill EQ page opens. B3 = Bypass. B1 or PAD FX = back. B3 (Edit) on the slot opens it again.
  • The load is one undo step, for example "Kill EQ Slot 1 T01".
  • The project saves the Kill EQ values.
  • On a track or a submix, the knobs record automation as on the effect page. The knobs keep the last value that played.

Tip: A Kill EQ on the master records no automation, as the stock effects there. For automation on all tracks, send the tracks to a submix with a Kill EQ, put the Kill EQ on each track, or use the EQ page of a pad.

Tip: Without SampQOL OS, the Kill EQ plays as the stock effect PEQ 2-Band, 2-Shelf: the bands do not go to kill, and fully right is +18 dB.

Master

The master has 4 slots with Pad FX, Flex Beat, Color Comp. and Knob FX, as in stock. The Knob FX slot shows the effect of FX Select, for example "(Knob FX) LP Filter".

  • Remove: select the slot, push SHIFT + B3, then B3 (Remove). This saves CPU. UNDO puts it back.

  • Hidden: in the same window, set B2 (Use Hidden) on. The effect keeps working, but it frees its slot. A grey line under slot 4 shows the hidden effects. The COMPRESSOR screen shows "Hidden" when the master Color Comp. is hidden. The screen of a hidden effect opens as usual.

  • Back to the master: select an empty slot and push B3 (Insert). The hidden effects are at the top of the list, for example "Flex Beat (Hidden)". Push B3 (Select): the effect goes to this slot, with its settings.

  • Pad FX, Flex Beat and Color Comp. can move to another slot (- / +). Knob FX stays on its slot.

  • Color Comp. Off = Bypass on the COMPRESSOR screen.

  • Edit (B3) opens the stock screen of the effect. PAD FX goes back to the Mixer, on the same slot.

  • When you open the screen of a removed effect, the MPC asks to put it back (B2 = Hidden, B3 = Insert; with 4 full slots: "MASTER FULL").

Channel Mixer and Pad Mixer

Push B2: Ch. Mixer, then Pad Mixer. Each mixer shows 8 strips per page. Turn the ENCODER to select a strip and to see more strips.

  • Ch. Mixer: the tracks with notes, the submixes in use, and the master.
  • Pad Mixer: the pads of the current track with a sample and notes. Play a pad to select its strip.
  • Each strip has a stereo meter (red above 0 dB). A peak line stays until you push SHIFT + ENCODER (all strips).
  • K1 = volume, K2 = pan (L50 to C to R50), K3 = output.
  • SHIFT + K2 = the mute group of the selected strip: Pad Grp, Trk Grp or Sub Grp (- = Off), as K2 on the insert page. Hold SHIFT to see the group. The master strip has no group: there, SHIFT + K2 is also pan. See Mute groups.
  • SHIFT + B1 (Inserts) opens the insert page of the selected strip. B2 goes back to the mixers.
  • The FADER also sets the volume of the selected strip, with the Fader Takeover of MIDI Config. When the FADER menu is Off, the FADER does nothing.
  • Volume with the ENCODER: push the ENCODER (yellow frame), turn it, and push it again to select strips again.
  • B3 = Mute, SHIFT + B3 = Solo. SHIFT + B2 (Clear M/S) turns off all mutes and solos of the page.
  • Mute on a track strip is Track Mute (see Record mutes).
  • Solo on a submix solos the tracks and pads that go to that submix.

Knob FX on all pads

The Knob FX is on the master. Every pad on every track plays through it.

Select another Knob FX effect without leaving your screen.

  2. Turn the ENCODER to select the next or previous effect in the list.

Mother Ducker

Mother Ducker makes a sound softer while another sound plays (a sidechain: for example, the bass gets softer on each kick). Mother Ducker Input goes on the sound that controls it, Mother Ducker on the sound that gets softer. They connect through a bus (Bus 1 to Bus 8).

  1. Put Mother Ducker Input on the kick (pad, track or submix) from the Insert FX list (Dynamics). Set K1 (Bus), for example Bus 1.
  2. Put Mother Ducker on the bass. Set K1 (Bus) to the same bus.
  3. Play both. Set K2 (Threshold) and K3 (Ratio) for how much the bass gets softer.

Under the title, each page shows the other part on the same bus:

Text Meaning
Input: A01 Kick Mother Ducker Input on pad A01 controls this Ducker.
Input: T02 Bass +1 Two or more parts are on this bus. The first one shows.
Input: A01 Kick (Bypass) The other part is bypassed (grey): no ducking.
No Input on Bus 2 No other part on this bus (grey): no ducking. Check K1 (Bus) on both parts.

On the Mother Ducker Input page, the text starts with Ducker:. K1 (Bus) always shows the bus on both pages.

The Mother Ducker page also shows GR (gain reduction, how much softer the sound is now) in dB, with an orange bar (0 to 60 dB). GR 0.0 = no ducking (also with Bypass on).

Tip: The ducking can be more than 60 dB. For a soft ducking, set K2 (Threshold) higher or K3 (Ratio) lower.

  • A new Mother Ducker starts with the stock values: Bus 1, -6 dB, 6:1, Attack 10 ms, Release 100 ms, Soft Knee 0 dB.

Loading and saving

Preview in Sample Select

In Sample Select, the pads preview the file. With Own Sample, a pad with a sample plays its own sound, to compare a file with your kit.

  1. Push SAMPLE SELECT and select an audio file.
  2. Push a pad. It becomes the selected pad (where a load goes) and plays the file to the end.
  3. Turn K3 (Prev. Vol.) to set the preview volume.

Tip: When a long folder name hides Prev. Vol., hold SHIFT to see it.

To compare the file with your kit:

  1. Turn SHIFT + K2 to the right (Own Sample).
  2. Push a pad that has a sample. It plays its own sound, and the selected pad does not change. The selected pad or an empty pad plays the file.
  3. Turn SHIFT + K2 to the left for Preview again.

B3 (Preview) is the stock auto-preview on/off. SHIFT + B3 is the stock Delete on the SD card.

Tip: The MPC keeps the K2 choice (Settings > Sample Select Pads Play). To load onto a pad with a sample in Own Sample, set Preview, or select the pad before you push SAMPLE SELECT.

New folder in Sample Select

  1. Push SAMPLE SELECT. Push B2 to select External (the SD card).
  2. Go to the folder where the new folder must go, and select a folder in it (in an empty folder, nothing is selected). B3 shows New Folder.
  3. Push B3. Type the name, as in stock.
  4. Push B3 (Do It!). B1 (Cancel) makes no folder.

If the name exists, the MPC makes no folder and shows "A folder with this name already exists" (B3 = OK). Internal is read-only: there, B3 does not show New Folder.

Browser

  • In SAMPLE SELECT and Load Project, hold SHIFT and turn the ENCODER to jump 10 rows.
  • In SAMPLE SELECT and Load Project, move the FADER to scroll the list (up = the first row). For the FADER menu function there, set Settings > Fader Scrolls List to Off.
  • The browser remembers your place in each folder.
  • Start Drive in Settings sets the drive at the start: SAMPLE BROWSER for Sample Select, PROJECT for Load Project.
  • The browser does not show the autorun folder (SampQOL OS) in the root of a drive. Use a computer to see it.
  • After an Eject of the SD card (SHIFT + B2), the card has the same path when you put it in again, so your Home Folder and Export folder stay correct. In stock, the card often got a new path.

Save to a folder

Save Sample and Save Project save in a folder that you choose.

  1. Open the name screen: SHIFT + SAMPLE SELECT (Save Sample), or SHIFT + PAD 16 and Save Project.
  2. Type the name, as in stock.
  3. Push B3 (Do It!). The folder page opens in the folder of your last save.
  4. Turn the ENCODER to select a folder. Push the ENCODER to open it. B1 (Up) goes one folder up (in the root of a drive: back to the name screen, no save). B2 selects Internal or External.
  5. Push B3 (Save). The MPC saves in the folder that the page shows.

For a name that exists, the MPC asks "Sample Already Exists" (as in stock) or PROJECT EXISTS (B3 = Overwrite, B1 = Cancel).

Tip: After start-up, the folder page opens in the stock folder (Samples/User or Projects/User; on the SD card: Projects), on the Start Drive of Settings.

Home Folder

Sample Select always opens in your own folder.

  1. In Settings, select Home Folder and push the ENCODER. The folder page opens.
  2. Select a folder as in Save to a folder (step 4).
  3. Push B3 (Use Folder). B1 (Back) in the root of a drive goes back with no change.
  4. Set Sample Select Opens to Home Folder.

Each time you push SAMPLE SELECT, the browser opens in the Home Folder. After a message or a SHIFT menu, the browser stays where you were.

Tip: If the Home Folder is not there (deleted, or no SD card), Sample Select opens on the Start Drive of SAMPLE BROWSER.

Random project name

  1. Go to Save Project (SHIFT + PAD 16).
  2. Hold SHIFT and push B3 (Random). The name field shows a random name, for example "Velvet Alley". Push again for a different name.
  3. Push B3 (Do It!) and select the folder (see Save to a folder).

New project with a template

  1. Open Settings and select Default Template. Push the ENCODER.
  2. Select a project (internal or SD card) and push the ENCODER. None = no template.

New Project asks: B1 = No, B2 = Empty (as in stock), B3 = Template. The template itself does not change: Save Project suggests the name "project".

Export mixdown and stems

Export makes WAV files (24-bit, 44.1 kHz) of a sequence.

  1. Save your project and stop the sequence.
  2. Push SHIFT + PAD 16, then B3 (Export).
  3. Select a row with the ENCODER. Push the ENCODER or turn K1 to change the value.
  4. Push B3 (Export). You cannot stop an export.
Row What it does
Sequence, Start, End The sequence (only sequences with events, for example S01 Intro (16 bars)) and the bars.
Export Mixdown One WAV of the full mix.
Mixdown Master FX The mixdown includes the master effects (also Knob FX). The stems never have them.
Export Stems One WAV for each track, with its submix effects. Together they sound as the mix without the master. A track that is muted in the sequence, or has no notes there, gives no file.
Tail Extra time after the end, for reverb and delay.
Folder The destination folder (push the ENCODER). Default: Samples/User/Export on the SD card.
Stems Folder Subfolder: the stems go in the folder Stems. Same: next to the mixdown.
BPM in Name The tempo in no file name (Off), the mixdown name (Mixdown) or all names (Mix + Stems).
Separator " - " or "_" between the parts of the file name.

  • The files go into a folder with the project name. The file names start with the project name; a stem also has the track number and name. Examples for "MyTrack" at 81 BPM:

    BPM in Name Separator Mixdown Stem
    Off " - " MyTrack.wav MyTrack - Tr01 - Drums.wav
    Mix + Stems " - " MyTrack - 81 BPM.wav MyTrack - 81 BPM - Tr01 - Drums.wav
    Mix + Stems "_" MyTrack_81BPM.wav MyTrack_81BPM_Tr01_Drums.wav

  • When you export only some bars, the name also has the bars, for example MyTrack - b2-5.wav.

  • If a file exists, select B2 (Keep Both) or B3 (Replace).

  • Without space, the MPC shows "Not enough space". An export to the internal storage stops when less than 200 MB is free.

  • If the card cannot save a file, the export stops with EXPORT FAILED, the file and the number of files that are OK. Push B3 (OK). Check the card on a computer, or use another card.

Tip: All sequences of a project get the same file name. To keep the export of each sequence, select Keep Both, or set BPM in Name when the sequences have different tempos.

Resample one pad

SampQOL OS can also resample one pad, as Flatten Pad on the large MPC.

  1. Select the pad that you want to resample.
  2. Push SHIFT + PAD 11 (Resample):
    • B1 = Cancel.
    • B2 = Pad: only the selected pad, one hit, with tail.
    • B3 = Seq: the full sequence (stock).
  3. With Pad, the line under "Select pad" shows which effects go into the new sample, for example Print Knob FX: On Pad FX: Off (On = the effect is on and its print is on). SHIFT + B3 (Knob FX) and SHIFT + B2 (Pad FX) set each print On (white box) or Off (white frame). The MPC keeps your last choices.
  4. With Pad, turn K1 or the ENCODER (1 second per step) to set the Tail (0 to 10 seconds, default 2). The tail is in the new sample only when an effect is in it (a pad insert, Knob FX or Pad FX). The MPC keeps the value. When the KNOB FX bar shows, K1 is the stock Knob FX function. A Sample Tail of the pad is always in the new sample, with the time that its fade needs.
  5. Push the destination pad.
  • In the new sample (then reset on the destination pad): tune, filter, envelopes, LFO, warp, start/end/loop, Offset, Sample Tail, layers and pad inserts. Stays on the destination pad: route, sends, mute targets, Mono/Poly, Mute Group and Amp Vel Sens.
  • Print On: the Knob FX or the Pad FX that are on are in the new sample, with the Tail. With Knob FX, the new sample has the volume of the source pad and the destination pad stays at 0 dB. With both Off, the new sample has no effects and the destination pad gets the volume of the source pad.
  • Chops: a chopped sample gives the new sample the same chops, at the same places in the sound (Tune, Warp and Reverse move them with the sound). Chops outside Start and End go. The destination pad gets Chop Type Manual. UNDO puts the old sample back, with its chops. Extract pads of the old sample do not change. No chops when the pad plays one chop only, or has more than one layer with a sample.
  • Track and submix effects and the other master effects are not in the new sample. A Hidden Knob FX or Pad FX is in it with its print On; other Hidden effects are not. Use a pad insert for that, or RECALL (SHIFT + SAMPLE RECORD): it records the last 25 seconds of the master output, with all master effects.

Tip: The new pad also plays through the Knob FX and the Pad FX that are on. With the print On you then hear the effect two times. Turn the effect off after the resample, or set the print to Off.

Tip: A pitch envelope, a pitch LFO or random pitch changes the speed during the sound. The chops then move by the mean speed, so they can be a little early or late. Check them in Chop Mode.

Tip: To put a Pad FX into the new sample, turn it on with Fixed or stock Latch (hold the pad and push B1) before SHIFT + PAD 11. An effect that you hold with your finger stops when you leave the Pad FX screen (stock). A Reverb or a Delay with much feedback needs more than 2 seconds of Tail.

Undo and Redo

Undo counter

SHIFT + - (Undo) and SHIFT + + (Redo) show a popup with the name of the step and a counter, for example Undo 2/7:

  • The first number is the quantity of steps that you undid.
  • The second number is the quantity of steps that the MPC keeps.

Example: three pushes of Undo show Undo 3/7. One Redo then shows Redo 2/7. Redo 0/7 = all steps are done again.

  • The MPC keeps a maximum of 512 steps. Then the oldest step goes.
  • Load Project and New Project delete all steps.
  • A knob turn without a stop is one step. A stop of more than 0.5 seconds starts a new step.
  • With no step to undo or redo, the MPC shows no popup.
  • Undo and Redo also work on SAMPLE RECORD.
  • Each Normalize, Trim, Extract and Resample keeps its version in its own sample file, so an Undo never removes a sample that an older step needs. The MPC deletes old versions when you start the MPC or load a project.
  • A sample on no pad does not go into the saved project. The MPC deletes it at the next start, as stock does.

Step names

The popup of a SampQOL OS step shows what changed (first line) and where (second line, for a name longer than 14 characters). Examples:

Popup Meaning
Copy A01 / to T04 A02 +2 Pad A01 copied to A02 of track 4 and 2 more pads
Extract A01 / to T02 A01-A16 The chops of A01 extracted to a new track 2
Velocity / S01/T01 A05 Step Edit: K3 changed pad A05 in sequence 1, track 1 (also Nudge, Length)
Erase S01/T01+2 Step Edit (Track View): track 1 and 2 more tracks
Effect Off / Slot 1 A01 Pad Mix: the effect in slot 1 of pad A01 is off

Stock steps keep their stock name, for example Add Event.

Compatibility and limitations

SampQOL OS works only on MPC Sample firmware 1.3.0. It is tested only with MPC Sample 1.3.0. Projects on an MPC One, Live or X (MPC OS 3.9.1) are not tested yet.

The mod writes what the MPC project format already has (notes, samples, mutes, drum tracks, inserts). Other data goes into the file .sampqol in the [ProjectData] folder, which stock and the MPC One, Live and X ignore. When you copy a project, copy the full [ProjectData] folder.

Tip: Save your SampQOL OS projects in a separate folder. Before you open one on a stock MPC Sample, make a copy.

Limitations

The limitations that change how you use a function are also a Tip in its section.

  • Chords on one pad. A KEYS or Scale chord is on one pad. On a stock MPC, a chord on a pad in Note On mode stops at the shortest note. ERASE, Mute and Solo act on all tones of that pad.
  • KEYS. A key adds no event in Step Edit (as in stock). The same note on a key and on a held 16 LEVELS pad stop each other at release (as in stock).
  • Knob FX. All pads play through it. See Knob FX on all pads.
  • Automate. See the Tips in Automate.
  • Stereo. Elsewhere, the pad plays both channels. See Stereo.
  • Track Volume. Only for pads with their output on the track. See Track Volume on the FADER.
  • Mute groups of tracks and submixes. A stock MPC does not know them. A recorded mute plays on each track, as recorded.
  • MIDI out. Two held pads on the same note and channel play one note. No undo for the MIDI setting. One MIDI Port for all tracks. See MIDI out.
  • Sequence change. When the MPC plays and you change the sequence (also in Song mode), you can hear a short gap. This occurs more with many tracks or effects.
  • Track mutes on stock. A stock MPC Sample does not play track mutes per sequence (also after Song Export). See Record mutes.
  • Audio track mute and pad outputs. A pad with Out set to a submix or an output stops at once, with a click (as in stock). See Record mutes.
  • Explode and Mute Targets. See Explode.
  • Internal storage. The internal storage always keeps about 400 MB free. When an edit or a save needs more, the MPC shows "Insufficient space on drive". A sample from the SD card is copied to the internal storage. Normalize makes a second, larger copy, kept until the next start for each step. Thus long samples fill the internal storage quickly. Stock also keeps an old copy of a long sample after an edit, a new chop or the end of Chop Mode, until the next save or load; SampQOL OS removes it after the edit, and at the end of Chop Mode for a new chop. See Troubleshooting.
  • Memory for big projects. Load Project and Load Kit do not load a project that is too big for the free memory (RAM). Each load of a big project keeps some memory in use until the next start, so a big project can load after a start but not after some other loads. See Troubleshooting.

Troubleshooting

The display does not show the SAMPQOL logo at start-up

  • The folder autorun must be directly on the card.
  • The card must have the format exFAT. Formatting deletes all on the card.
    • Mac: Disk Utility > select the card > Erase > ExFAT.
    • Windows: File Explorer > right-click the card > Format > exFAT > Start.
  • Do not change or open the files in the folder: the MPC ignores a changed folder. Copy the folder autorun from the zip file again.
  • The firmware must be 1.3.0 (step 1 of Install). On other firmware, the MPC starts as stock.

The display does not show v1.3.0

The display shows only v1.3.0 for the correct firmware 1.3.0.12.

  • Lower than 1.3.0: install 1.3.0 with the MPC Sample 1.3.0 Updater. Do not install a higher version.
  • Higher than 1.3.0: do not use the mod on this firmware.

With the SD card in, the MPC is stock

  • Set the MPC off and on again.
  • Still stock? Check the firmware version (step 1 of Install).

The start-up stops at 0.0%

Push B1. The MPC then continues the start-up.

The MPC hangs at start-up, or SampQOL OS does not work

The MPC does not ask a question at start-up, so you cannot select stock there. Do these steps:

  1. Push and hold the power button until the MPC goes off.
  2. Remove the card. Set the MPC on. It is stock again.
  3. To try SampQOL OS again, put the card back in. SampQOL OS starts at once. If the problem stays, do step 1 and 2 again, then step 4.
  4. On a computer, rename or move the folder autorun (see Go back to stock). Your projects and samples on the card do not change.
  5. Put the card back in the MPC. Stock uses the card at once.

The files events.log and last-exit.log in its folder logs show what happened.

The installation is correct, but SampQOL OS does not work

Also when the card has the format exFAT already:

  1. Copy your projects and samples from the card to the computer. Formatting deletes all on the card.
  2. Format the card again as exFAT (see The display does not show the SAMPQOL logo at start-up).
  3. Do all steps of Install again. Do each step exactly as written.

Insufficient space on drive

This message is about the internal storage, not the SD card. The internal storage always keeps about 400 MB free.

  1. Push B1 (Clear) to delete the undo history. This gives back the space of the samples that only the undo history used.
  2. Set the MPC off and on. This gives back the rest of the space.
  • Save your projects and samples on the SD card.
  • Keep the internal storage as stock as possible. Move your own projects and samples from the internal storage to the SD card.

Not enough memory

The project or kit is too big for the free memory (RAM). The MPC does not load it. Your open project stays as it is.

  1. Push B3 (OK).
  2. Save your project.
  3. Set the MPC off and on. This gives back all the memory.
  4. Load the project again.

Tip: Only very big projects need this, for example 16 tracks with about 60 full sequences. A smaller project uses less memory: delete the sequences that you do not use.

The MPC goes back to stock while you play

The mod crashed two times within 2 minutes. Set the MPC off and on to get SampQOL OS back. The files events.log and last-exit.log in autorun/logs on the card show what happened.

The computer lost the SD card

SampQOL OS crashed during SD Card Access. The watchdog disconnects the card from the computer before the MPC uses it again, so they do not use the card at the same time.

  1. Wait until SampQOL OS has started again.
  2. Open SD Card Access again (SHIFT + PAD 16).
  3. On the computer, check the files that you copied last. Copy them again if they are not complete.

The file events.log in autorun/logs on the card shows the line "in SD Card Access: USB set back to normal".
